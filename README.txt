随机开局 · User 设定 v0.1.0

安装
1. 解压压缩包，得到 random-start 文件夹。
2. 把整个文件夹放入 SillyTavern/public/scripts/extensions/third-party/。
   最终结构应为 third-party/random-start/manifest.json 和 index.js，避免多套一层目录。
3. 刷新酒馆页面。在扩展设置中找到“随机开局 · User 设定”。
4. 先连接你平时聊天使用的 API，再点击“一键随机开局”。输入框附近的扩展快捷菜单也有随机入口。

流程
所有已导入的单人角色卡等概率抽取一张，再从主开场和备选开场中等概率抽一个，建立新聊天，后台生成 User 设定。旧聊天保留。没有可用开场的卡会提示失败，不会编造开场。
默认模板为用户提供的完整字段，可在扩展设置修改并自动保存。
调用酒馆当前连接的 API 与当前预设，使用普通 quiet 生成流程，生成长度请求为 2400 tokens，实际仍受模型、服务商和预设限制。
世界书按酒馆原有的启用、关键词、quiet 触发和预算规则参与，不保证全部条目进入提示词。角色卡中未启用的世界书不会自动开启。

当前聊天专属设定
生成结果保存在 chat_metadata.random_start_user，随聊天保存。扩展在该聊天中将其作为用户人物设定注入；切换聊天时自动更新或清除注入。
这不是创建全局 Persona，也不改变界面用户名和头像。提示词明确当前界面用户名是生成角色的别名，{{user}}仍显示酒馆原来的用户名。角色卡或其他扩展中强制覆盖用户身份的指令可能产生冲突。
在“查看 / 修改当前聊天设定”里可以修改并保存，空内容会停止注入。
请在完成前留在当前聊天，不要发送消息、切换开场或切换 API。若 API 失败，留在新聊天中点击“重试生成”；重试不会再抽卡。已经开始正式聊天后不允许重试覆盖。
失败时不自动删除新建聊天。
性相关字段限定成年人物；生成时检查明确年龄为18以上，仍请自行检查模型输出。

验证与兼容性
参照官方 SillyTavern release 源码 1.19.0，提交 06bde93 核对接口。
通过 JavaScript 语法检查及模拟测试：随机范围、开场池过滤、设定保存与注入、切换聊天清除注入、切换中拒绝回写、空输出及年龄校验。
未在用户实际酒馆与真实 API 中运行。旧版本可能不兼容，请提供版本号和报错以进一步适配。
